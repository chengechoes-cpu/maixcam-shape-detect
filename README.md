# MaixCAM 视觉形状识别（产线检测原型）

> 摄像头实时取景 → 阈值分割出目标色块 → 用几何特征判定 圆 / 矩形 / 三角形 → 屏幕叠加显示并把结果打到串口。

用于产线检测类场景的原型验证（零件分类、有无检测），跑在 MaixCAM（MaixPy 生态）。

---

## 原理

不做深度学习，用**传统几何特征**判形状 —— 在这类只分几类的场景里，
比训练模型快、稳、可解释，现场阈值可调：

| 特征 | 计算 | 判定 |
|---|---|---|
| `circularity` = 4π·area / perimeter² | 越接近 1 越圆 | > 0.72 且长宽比 0.75~1.30 → **CIRCLE** |
| `fill_ratio` = area / (w·h) | 外接矩形填充率 | > 0.65 → **RECT** |
| 同上 | | 0.35~0.65 → **TRI** |
| 其他 | | UNKNOWN |

参数（阈值、最小像素、最小面积）在文件头，现场调参不用重新理解逻辑。

## 输出

- 屏幕：实时画面 + 目标框 + 形状标签
- 串口：只在结果**变化**时打印一行（去抖，避免刷屏）

```
CIRCLE
RECT
TRI
```

这两个信号（屏幕 + 串口）就是给下游 PLC / 单片机 / 上位机的接口。

## 文件

| 文件 | 作用 |
|---|---|
| `main.py` | 主程序：取景 → 阈值 → blob 分析 → 形状分类 → 显示/串口输出 |
| `camera_test.py` | 最小验证：能否打开摄像头 + 屏幕出图（排接线用） |
| `docs/rs485.png` | 现场接线参考图 |

## 运行

把 `main.py` 传到 MaixCAM 上，通过 MaixVision / SSH 执行：

```bash
python main.py
```

先跑 `camera_test.py` 确认硬件通路（屏幕能否显示 `AUTO RUN OK`），再跑 `main.py`。

## 已知限制

- 单一阈值 `THRESH = [(0, 80)]` 只对深色目标有效；浅色/反光件要改阈值，或扩展到 LAB 色彩空间。
- 只支持单目标（取最大 blob），多零件同框需要聚类后逐个分类。
- 光照变化是最大干扰源；产线部署建议加固定光源。
- 圆/矩/三角之外（如六角、异形）都会落到 UNKNOWN，需要扩充分类分支。
